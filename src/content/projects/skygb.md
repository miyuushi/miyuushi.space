SkyGB is a Game Boy emulator written entirely in JavaScript.  
It emulates the original hardware to run classic Game Boy titles in the browser.

The project focuses on accuracy while remaining lightweight and portable.

**Highlights**
- Game Boy CPU emulation
- Browser-based execution
- Pure JavaScript implementation
