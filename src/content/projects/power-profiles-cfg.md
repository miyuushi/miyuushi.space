power-profiles-cfg extends power-profiles-daemon with configurable CPU behavior.  
It allows defining custom CPU governors and turbo settings for each power profile.

This enables finer control over performance and power consumption on Linux systems.

**Highlights**
- Custom CPU governor configuration
- Turbo boost control
- Integration with power-profiles-daemon
