Veggify is a vegan and vegetarian restaurant finder built using OpenStreetMap data.  
It provides fast geospatial search and filtering to help users discover plant-based dining options.

The backend is written in Rust using Axum, with PostgreSQL and PostGIS handling spatial queries.  
The frontend uses Astro with Svelte for a lightweight and responsive UI.

**Highlights**
- OpenStreetMap data ingestion
- Geospatial queries with PostGIS
- Rust backend (Axum)
- Astro + Svelte frontend
