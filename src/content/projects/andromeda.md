Andromeda is a plugin framework for hooking and overriding game functions.  
It enables creating overlays and extending functionality through a modular plugin system.

The project is written in Rust and designed with flexibility and performance in mind.

**Highlights**
- Function hooking framework
- Overlay rendering support
- Plugin API
- Written in Rust
