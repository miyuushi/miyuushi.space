Lunaire is a retro-inspired 16-bit computer design built around the 65816 processor.  
The system combines classic hardware components with modern FPGA-based video output.

It features a YM3812 sound chip for audio, dual VIA chips for I/O, and an FPGA responsible for generating video signals.

**Highlights**
- 65816 16-bit CPU
- YM3812 sound chip
- Dual VIA I/O controllers
- FPGA video output
